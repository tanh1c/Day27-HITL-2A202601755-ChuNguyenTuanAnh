# Lab 27 HITL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a submission-ready LangGraph HITL workflow matching every Lab 27 requirement plus automated quality evidence.

**Architecture:** Deterministic churn reasoning feeds hard-policy-first conditional routing. `MemorySaver` plus a static pre-execution breakpoint pauses high-risk paths; Streamlit updates state and resumes the same thread. Pydantic audit records are appended to JSON atomically.

**Tech Stack:** Python 3.10+, LangGraph 1.2.11, LangChain 1.3.18, Streamlit 1.62.0, Pydantic 2.13.5, pytest, Ruff, mypy, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-29-lab27-hitl-design.md`

## Global Constraints

- Confidence threshold is exactly `0.85`.
- `increase_credit_limit` always requires review regardless of confidence.
- Compile with `MemorySaver()` and `interrupt_before=["execute_high_risk_action"]`.
- Keep submitted repository free of real credentials.
- Avoid duplicate CI triggers; PR + manual dispatch only.
